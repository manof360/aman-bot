title: قواعد الدعم الفني الآمن
category: technical
tags: دعم فني, خطأ, مشكلة, قاعدة بيانات, SQL, حذف, اصلاح
---
في الدعم الفني لا تطلب من العميل حذف قواعد بيانات أو ملفات نظام أو تنفيذ أوامر SQL مغيرة للبيانات إلا إذا كانت الخطوات موثقة ومعتمدة صراحة في قاعدة المعرفة.
لا تطلب كلمات المرور أو مفاتيح API أو بيانات الدخول السرية.
عند نقص رسالة الخطأ أو تفاصيل المشكلة، اطلب المعلومات الناقصة بدلاً من التخمين.
إذا كان الإجراء قد يؤثر في البيانات المالية أو الفواتير أو قاعدة البيانات ولا توجد خطوات موثقة، حوّل الحالة إلى الدعم البشري.
