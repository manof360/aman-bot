# Aman Bot V3.2

بوت شركة أمان الحديثة لدعم ومبيعات منتجات المحاسب الشامل عبر WhatsApp Cloud API.

## ما يعمل الآن
- Webhook رسمي مع التحقق من توقيع Meta.
- SQLite للجلسات والرسائل والتذاكر وdeduplication.
- AI grounded: لا يجيب إلا من سياق قاعدة المعرفة المسترجع.
- قاعدة معرفة Markdown منظمة حسب المنتجات والقطاعات والدعم وZATCA والمبيعات.
- بحث محلي موزون يعتمد على العنوان والوسوم والمحتوى، دون تكلفة Vector DB.
- اختبارات أولية للاسترجاع.

## قاعدة المعرفة
المجلد knowledge/ هو المصدر المعتمد. كل ملف Markdown يحتوي frontmatter: id وtitle وcategory وtags ثم النص الموثق.

المحتوى الأولي يشمل:
- قدرات المحاسب الشامل الأساسية.
- قطع الغيار.
- المقاولات والمشاريع مع توضيح الميزات غير المتوفرة.
- الصيدليات وRSD.
- مواد البناء والأدوات الكهربائية.
- ZATCA.
- قواعد الدعم الآمن.
- مشاكل الشبكة الأولية.
- طلب التجربة والمبيعات.

## التشغيل
انسخ .env.example إلى .env، أدخل بيانات Meta وGroq ثم:
npm install
npm test
npm start

## الخطوة التالية
إثراء قاعدة الدعم الفني بحلول حقيقية معتمدة: الطابعات، SQL Server، النسخ الاحتياطي، الشبكات، أخطاء ZATCA. بعدها نقيّم جودة البحث؛ إذا كبرت المعرفة بما يكفي نضيف embeddings/vector search بدلاً من إدخال Vector DB مبكراً.
